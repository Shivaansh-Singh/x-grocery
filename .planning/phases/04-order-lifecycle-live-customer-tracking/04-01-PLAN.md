# Plan 04-01: Order Creation API, Price Snapshotting & Tabbed Order History View

## Executive Summary

Build the order creation API (`POST /api/orders`) preserving item price and name snapshots in `OrderItem`, the order listing API (`GET /api/orders`), and the tabbed Order History page (`/orders`) displaying active and past order cards with live tracking links.

---

## Tasks

<task_block>
### Task 04-01-01: Create Order Creation & Listing API (`src/app/api/orders/route.ts`)
**Goal**: Build a server route handler to create orders with unique `XG-XXXXXX` order numbers, frozen `OrderItem` price snapshots, initial `PENDING` status, and fetch customer orders.
**Files**: `src/app/api/orders/route.ts`
**Requirements**: ORD-01, ORD-02
**Threat Ref**: T-04-01 (Order price tampering)
**Secure Behavior**: Server calculates item subtotal from `OrderItem` inputs and verifies totals before saving.

**Verification**: `npm run lint && npx tsc --noEmit`
</task_block>
