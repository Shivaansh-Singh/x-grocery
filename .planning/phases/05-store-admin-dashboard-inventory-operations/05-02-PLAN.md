# Plan 05-02: Admin Incoming Orders Board, 1-Tap Accept/Reject, Rider Assignment & Delivery Roster

## Executive Summary

Build the admin order management API (`/api/admin/orders/[id]`), delivery staff API (`/api/admin/delivery-staff`), incoming order processing board (`/admin/orders`), 1-tap Accept/Reject action workflow with rejection reason modal, status advancement buttons, rider selector dropdown, delivery staff roster page (`/admin/delivery-staff`), and automated stock reconciliation upon order acceptance.
