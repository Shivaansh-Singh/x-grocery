# Plan 01-01: Prisma Schema, Supabase Client & Store X Seed Script

## Executive Summary

Establish the foundational relational database models using Prisma ORM with explicit `store_id` multi-store structural abstraction, setup Supabase authentication client helpers, and build an executable seed script (`prisma/seed.ts`) populating Store X, 6 student grocery categories, 15+ realistic products with images and stock, Store Admin X, and 2 delivery staff users.

---

## Tasks

<task_block>
### Task 01-01-01: Install Prisma & Supabase Dependencies
**Goal**: Add Prisma ORM, Supabase Auth SSR SDK, and seed helper dependencies to `package.json`.
**Files**: `package.json`
**Requirements**: DB-01
**Secure Behavior**: Dependencies installed from official NPM registry.

```bash
npm install @prisma/client @supabase/supabase-js @supabase/ssr tsx
npm install -D prisma
```

**Verification**: `npm run lint && npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-01-02: Create Prisma Relational Schema (`prisma/schema.prisma`)
**Goal**: Write the complete relational Prisma schema enforcing `store_id` multi-store readiness, inventory audit logs, unit enums, and order status lifecycle.
**Files**: `prisma/schema.prisma`
**Requirements**: DB-01, DB-02
**Threat Ref**: T-01-01 (Unauthorized multi-store data leakage), T-01-02 (Inventory race condition overselling)
**Secure Behavior**: All product, category, and order models strictly bound to `store_id` with relational foreign key cascading.

Define models:
- `User` (`Role` enum: `CUSTOMER`, `STORE_ADMIN`, `DELIVERY_PARTNER`)
- `CustomerAddress` (Structured fields for off-campus housing)
- `Store` (Store X representation)
- `Category` (`storeId`, `name`, `slug`, `icon`, `sortOrder`)
- `Product` (`storeId`, `categoryId`, `name`, `slug`, `price`, `imageUrl`, `unitType`, `unitQuantity`, `unitDisplay`, `stock`, `isActive`)
- `InventoryLog` (`productId`, `previousStock`, `newStock`, `changeQuantity`, `reason`, `updatedById`)
- `Order` (`orderNumber`, `storeId`, `customerId`, `deliveryPartnerId`, `status`, `paymentMethod`, `paymentStatus`, `totalAmount`, `deliveryAddress`)
- `OrderItem` (`orderId`, `productId`, `productName`, `unitPrice`, `quantity`, `subtotal`)

**Verification**: `npx prisma validate`
</task_block>

<task_block>
### Task 01-01-03: Setup Prisma & Supabase Client Singletons
**Goal**: Create server-safe singleton instances for Prisma ORM and Supabase Auth client/server SDKs.
**Files**: `src/lib/prisma.ts`, `src/lib/supabase/client.ts`, `src/lib/supabase/server.ts`
**Requirements**: DB-01, AUTH-01
**Secure Behavior**: Cookies managed securely via `@supabase/ssr` server utilities; Prisma client attached to `globalThis` in development.

**Verification**: `npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-01-04: [BLOCKING] Build Store X Seed Script (`prisma/seed.ts`)
**Goal**: Create an executable seed script populating Store X, 6 student categories, 15+ grocery items with realistic prices/images/stock, Admin X, and 2 delivery staff accounts.
**Files**: `prisma/seed.ts`
**Requirements**: DB-01, DB-02

Seed content:
- Store X: `name: "Store X (VIT Bhopal Off-Campus Hub)"`, `slug: "store-x"`
- Categories: `Fresh Produce`, `Dairy & Eggs`, `Snacks & Munchies`, `Instant Noodles & Ready Meals`, `Beverages & Drinks`, `Hostel Essentials`
- 15+ student grocery products with stock (e.g., Maggi 2-Min Noodles, Amul Taaza Milk, Lays Chips, Bananas, Mineral Water, Eggs)
- Users: Store Admin (`admin@x-grocery.com`), Delivery Partner 1 (`delivery1@x-grocery.com`), Delivery Partner 2 (`delivery2@x-grocery.com`), Test Customer (`student@vitbhopal.ac.in`)

**Verification**: `npx tsx prisma/seed.ts`
</task_block>
