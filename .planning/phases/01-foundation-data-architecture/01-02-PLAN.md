# Plan 01-02: Auth RBAC Middleware, Mobile App Shell & App Brand Config

## Executive Summary

Implement server-side Role-Based Access Control middleware (`src/middleware.ts`) guarding `/admin` (Store Admin X) and `/delivery` (Delivery Staff) routes, establish centralized branding configuration (`src/config/app.config.ts`), and build a responsive mobile app shell with top brand header and 5-tab bottom navigation (`Home`, `Categories`, `Cart`, `Orders`, `Profile`).

---

## Tasks

<task_block>
### Task 01-02-01: Create Centralized App Branding Config (`src/config/app.config.ts`)
**Goal**: Create a single configuration file for app name, taglines, service area descriptions, and asset references.
**Files**: `src/config/app.config.ts`
**Requirements**: AUTH-01
**Secure Behavior**: Prevents hardcoded brand strings across components; facilitates clean rebranding.

```typescript
export const appConfig = {
  appName: "x-grocery",
  displayName: "X-Grocery",
  tagline: "Instant Grocery Delivery in 10-15 Mins",
  serviceArea: "Off-Campus VIT Bhopal (Flats, Rooms & PGs)",
  contactEmail: "support@x-grocery.com",
  storeId: "store-x-vit-bhopal",
};
```

**Verification**: `npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-02-02: Create Server Middleware for RBAC Route Protection (`src/middleware.ts`)
**Goal**: Intercept all incoming HTTP requests server-side, refreshing Supabase auth tokens and checking user role claims to enforce RBAC route security.
**Files**: `src/middleware.ts`
**Requirements**: AUTH-01, AUTH-02
**Threat Ref**: T-01-04 (Unauthorized route privilege escalation)
**Secure Behavior**:
- Unauthenticated access to `/admin` or `/delivery` redirects to `/login`.
- Non-admin users accessing `/admin` redirect to `/` with error notification.
- Non-delivery staff accessing `/delivery` redirect to `/`.

**Verification**: `npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-02-03: Create Client Auth Session Provider (`src/components/providers/AuthProvider.tsx`)
**Goal**: Provide React Context for current user, session, and role (`CUSTOMER`, `STORE_ADMIN`, `DELIVERY_PARTNER`) across client components.
**Files**: `src/components/providers/AuthProvider.tsx`
**Requirements**: AUTH-01
**Secure Behavior**: Listens for Supabase auth state changes and synchronizes session cookies.

**Verification**: `npm run lint && npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-02-04: Build Mobile App Shell & Navigation Layout
**Goal**: Build a responsive mobile app shell frame with a sticky top header (location badge & app title) and a 5-tab bottom navigation bar (`Home`, `Categories`, `Cart`, `Orders`, `Profile`).
**Files**: `src/components/layout/Header.tsx`, `src/components/layout/BottomNav.tsx`, `src/components/layout/AppShell.tsx`, `src/app/layout.tsx`
**Requirements**: AUTH-01

Features:
- Header: Brand title from `appConfig.displayName`, location indicator ("VIT Bhopal Off-Campus"), role indicator badge.
- BottomNav: Active tab highlighting, icon badges for cart item counts.

**Verification**: `npm run lint && npx tsc --noEmit`
</task_block>

<task_block>
### Task 01-02-05: Create Route Shell Pages (`/`, `/admin`, `/delivery`, `/login`)
**Goal**: Create page entry shells for customer home, store admin dashboard (`/admin`), delivery partner portal (`/delivery`), and authentication (`/login`).
**Files**: `src/app/page.tsx`, `src/app/admin/page.tsx`, `src/app/delivery/page.tsx`, `src/app/login/page.tsx`
