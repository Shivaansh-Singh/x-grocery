# Plan 02-02: Product API, Debounced Search, 2-Column Product Grid with Stock Badges & Detail Drawer

## Executive Summary

Build the products discovery API (`GET /api/products`), debounced instant search bar, 2-column mobile product grid with stock badges (`Out of Stock` & `Only N Left!`), inline quantity steppers, and mobile slide-up product detail drawer.

### Task 02-02-01: Create Products Filtering API Endpoint (`src/app/api/products/route.ts`)
**Goal**: Build a server-side route handler to filter products by `category` slug and `search` text query for Store X.
**Files**: `src/app/api/products/route.ts`
**Requirements**: CAT-02, CAT-03
