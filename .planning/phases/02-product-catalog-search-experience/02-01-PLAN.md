### Task 02-01-01: Create Category API Endpoint (`src/app/api/categories/route.ts`)
**Goal**: Build a server-side route handler to fetch Store X categories ordered by `sortOrder`.
**Files**: `src/app/api/categories/route.ts`
**Requirements**: CAT-01
**Threat Ref**: T-02-01 (Unauthorized data access across stores)
**Secure Behavior**: Hardcode/default `storeId` filter to Store X (`store-x` slug / Store X ID) to prevent cross-store data leakage.

```typescript
import { NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";

export async function GET() {
  const store = await prisma.store.findUnique({
    where: { slug: "store-x" },
  });

  if (!store) {
    return NextResponse.json({ error: "Store X not found" }, { status: 404 });
  }

  const categories = await prisma.category.findMany({
    where: { storeId: store.id },
    orderBy: { sortOrder: "asc" },
  });

  return NextResponse.json({ categories });
}
```

**Verification**: `npm run lint && npx tsc --noEmit`
